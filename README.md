Dairy Farm Management System

Overview

The Dairy Farm Management System is a C++ console-based application developed to simplify dairy farm operations. It provides a menu-driven interface for managing animal records, milk production, feed records, health records, and sales. The system stores data in a file, allowing records to persist between program executions.

Features

- Secure login authentication
- Animal Management (Add, View, Search, Update, Delete)
- Milk Production Management
- Feed Management
- Health Record Management
- Sales Management
- Input validation for reliable data entry
- File handling for permanent data storage
- Menu-driven console interface

Technologies Used

- C++
- Object-based programming using structures
- File Handling (fstream)
- Console Application

Project Structure
